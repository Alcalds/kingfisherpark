# KINGFISHER PARK — RESPONSIVE QA CHECKLIST

## Scope
Homepage + interactive booking prototype.

## Target widths
- 1600px desktop
- 1440px desktop
- 1280px laptop
- 1024px tablet landscape
- 768px tablet
- 430px mobile
- 390px mobile
- 360px small mobile

## Homepage checks
- Header does not overlap important Hero copy.
- Mobile navigation remains keyboard-operable.
- Hero fireflies reduce in quantity on smaller screens.
- Hero calls to action remain at least 44px high.
- Visit Snapshot collapses cleanly.
- Experience cards stack on mobile.
- Day-to-Night sections do not overflow horizontally.
- Fixed mobile booking CTA does not cover footer content.
- Historical/archive labels remain visible.

## Booking checks
- Progress bar can scroll horizontally on narrow screens.
- Mobile step/total status remains visible below the header.
- Experience selection cards are touch-friendly.
- Date field does not invent a time slot.
- Guest controls are at least 44px.
- Form inputs use 16px on small screens to reduce mobile browser zoom.
- Review total remains legible.
- Demo Payment never asks for payment credentials.
- Confirmation remains printable.
- Live summary remains readable on tablet/mobile.
- No horizontal page overflow.

## Accessibility checks
- Skip links available.
- Keyboard navigation supported.
- Escape closes mobile navigation.
- Focus states remain visible.
- Step headings receive focus after step changes.
- Validation errors use an assertive live region.
- Booking summary/mobile status use polite live updates.
- Reduced-motion preference is respected.

## Publication blockers still pending
- Exact booking time slots
- Capacity limits
- Cancellation/refund/rescheduling/no-show rules
- Child / senior / PWD / group rates
- Final map/entrance location
- Payment provider
- Payment/processing fees if any
- New renovated-facility photographs
