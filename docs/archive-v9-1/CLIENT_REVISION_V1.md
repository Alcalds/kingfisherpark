# Kingfisher Park — Client Revision V1

This revision responds to client/staff feedback and the Yosemite planning-content benchmark.

## Changes

- Increased meaningful supporting font sizes across the site.
- Simplified mobile Hero metadata to reduce clutter.
- Strengthened the Hero booking CTA with rate/context microcopy.
- Strengthened the persistent mobile booking bar.
- Added a booking step: **Know What to Expect**.
- Booking flow is now: Experience → What to Expect → Date & Time → Guests → Details → Review → Demo Payment → Confirmation.
- Added **First Time at Kingfisher Park?** guidance on Plan Your Visit.
- Added a **Free Visitor Guide** callout and a new `visitor-guide.html` print/save prototype.
- Added a Visitor Guide prompt to all page footers.
- Preserved current verified hours/rates and did not invent final slots, capacity, policies, directions or facilities.
