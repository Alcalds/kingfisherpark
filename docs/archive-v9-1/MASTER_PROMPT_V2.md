# 38. HERO FIREFLY EFFECT

The Kingfisher Park Hero should include a custom, lightweight **firefly-inspired ambient animation**.

The fireflies are a **decorative interface effect**, not documentary wildlife footage.

## EXPERIENCE GOAL

The effect should feel:

- quiet
- organic
- subtle
- atmospheric
- premium
- natural

It should support the Hero without becoming the main subject.

## IMPLEMENTATION

For the VS Code prototype, prefer:

**HTML Canvas + vanilla JavaScript**

Do not add a third-party particle library unless there is a compelling technical reason.

Recommended layering:

1. authentic Hero photograph
2. image treatment / environmental gradient
3. subtle firefly canvas
4. Hero copy
5. navigation/header

The copy must remain readable at all times.

## PARTICLE BEHAVIOR

Desktop starting target:

approximately **20–35 visible firefly particles**, adjusted by actual visual testing.

Use fewer particles on tablet and mobile.

Particles should have:

- varying small sizes
- soft blurred glow
- warm yellow / yellow-green luminosity
- slow drifting movement
- irregular directional changes
- different brightness levels
- individual pulse timing
- occasional fade-in/fade-out behavior
- varied lifespan

Avoid synchronized movement.

Avoid uniform spacing.

Avoid filling the entire screen evenly.

Favor areas of the image where fireflies would feel compositionally natural, while keeping the main text area comparatively calm.

## DO NOT MAKE THE EFFECT LOOK LIKE

- snowfall
- stars
- glitter
- confetti
- sparks
- embers
- fairy dust
- a gaming particle system

## ACCESSIBILITY

Respect:

`prefers-reduced-motion`

When reduced motion is requested:

- disable particle movement, or
- show only a very small static/slow luminous treatment

The Hero must remain visually complete without animation.

## PERFORMANCE

- use `requestAnimationFrame`
- scale canvas for device pixel ratio carefully
- reduce particle count on small screens
- pause animation when the document/tab is hidden
- avoid excessive blur calculations
- avoid unnecessary DOM elements
- stop animation when it is not useful

## AUTHENTICITY

The firefly animation must never be described as a literal representation of actual firefly density or guaranteed sightings at Kingfisher Park.

It is a visual design device inspired by the nighttime experience.
